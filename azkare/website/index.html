التثبيت التلقائي (موصى به)

١
أمر واحد — يثبّت كل شيء تلقائيًا

يكتشف توزيعتك ويثبّت التبعيات والخطوط ويبني ويثبّت أذكاري.

bash
$ curl -fsSL https://raw.githubusercontent.com/arcalc/azkare/main/install.sh | bash

البناء اليدوي من المصدر

٢
استنساخ وبناء
bash
$ git clone https://github.com/arcalc/azkare.git && cd azkare && cmake -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build -j$(nproc) && sudo cmake --install build

إدارة التطبيق من الطرفية

٣
bash
$ azkare --update # تحديث azkare --settings # الإعدادات azkare --next # الذكر التالي azkare --uninstall # إلغاء التثبيت

التثبيت التلقائي (PowerShell)

1
افتح PowerShell كمسؤول وشغّل:

يثبّت كل التبعيات تلقائيًا عبر winget ثم يبني أذكاري.

PowerShell
PS> irm https://raw.githubusercontent.com/arcalc/azkare/main/install.ps1 | iex

إدارة التطبيق

2
PowerShell
PS> azkare --update azkare --settings azkare --uninstall

التثبيت التلقائي

1
تأكد من تثبيت Homebrew أولاً ثم شغّل:
zsh
% curl -fsSL https://raw.githubusercontent.com/arcalc/azkare/main/install.sh | bash
2
إذا لم يكن Homebrew مثبتًا:
zsh
% /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
