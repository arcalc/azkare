تثبيت بأمر واحد

أمر واحد يثبّت التبعيات والخطوط ويبني من المصدر — بلا ملفات تنزيل يدوية.

Linux · macOS · Windows

طبقة سطح المكتب

يظهر الذكر فوق الخلفية وتحت نوافذك دون أن يسرق التركيز. X11 وWayland (layer-shell).

مرجع لكل ذكر

كل ذكر يحمل مرجعه (البخاري، مسلم، القرآن…). المجموعة الحالية بداية وتنمو، والمراجعة العلمية مرحَّب بها.

توقيت مرن

من ٣٠ ثانية إلى ساعة أو أي مدة تختارها، للعرض وللإشعارات كلٌّ على حدة.

إشعارات النظام

عبر D-Bus على لينكس، وإشعارات Qt الأصلية على ويندوز وmacOS.

خطوط عربية مدمجة

أميري، شهرزاد، نوتو نسخ، كايرو، IBM Plex العربي، عرف رقعة — مدمجة في البرنامج.

دعم eww على لينكس

اختر eww كمحرك عرض بديل؛ يكتب أذكاري إعداداته في مجلد خاص ولا يمس إعداداتك.

إعدادات بلغة بسيطة

عربي (يمين لليسار) وإنجليزي، وتحت كل خيار شرح بسيط، مع معاينة حية للخط واللون.

تثبيت تلقائي بأمر واحد (موصى به)

يكتشف توزيعتك (Arch / Debian / Ubuntu / Fedora / openSUSE / Alpine)، يثبّت التبعيات والخطوط، يبني ويثبّت في ~/.local/bin.

bash
curl -fsSL https://raw.githubusercontent.com/arcalc/azkare/main/install.sh | bash
2

بناء يدوي من المصدر

bash
git clone https://github.com/arcalc/azkare.git && cd azkare && bash scripts/fetch-fonts.sh && cmake -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build -j && sudo cmake --install build
3

التحكم والتحديث وإلغاء التثبيت

تشغيل في الخلفية، الإعدادات، التشغيل التلقائي، التحديث، ثم الإزالة الكاملة.

bash
azkare
azkare --settings
azkare --autostart on
azkare --update
azkare --uninstall

مُختبَر على Ubuntu 24.04 مع X11. على Wayland يلزم تثبيت layer-shell-qt (يحاول المثبّت تثبيته)، وعلى GNOME بلا layer-shell يظهر النص كنافذة عادية.

تثبيت تلقائي بأمر واحد (موصى به)

يثبّت Git وMSYS2 عبر winget (أو choco/scoop) ثم المترجم وQt6 داخل MSYS2، ويبني ويضيف المسار إلى PATH.

PowerShell
irm https://raw.githubusercontent.com/arcalc/azkare/main/install.ps1 | iex

PowerShell
git clone https://github.com/arcalc/azkare.git; cd azkare; $env:MSYSTEM='UCRT64'; $env:CHERE_INVOKING='1'; & C:\msys64\usr\bin\bash.exe -lc 'bash scripts/fetch-fonts.sh; cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release && cmake --build build -j'

تثبيت تلقائي بأمر واحد (موصى به)

يثبّت التبعيات عبر Homebrew، يُنزّل الخطوط، يبني ويثبّت في ~/.local/bin.

zsh
curl -fsSL https://raw.githubusercontent.com/arcalc/azkare/main/install.sh | bash

zsh

مرجع أوامر الطرفية

تحكّم كامل بدون واجهة رسومية (ولا يحتاج شاشة: يعمل عبر SSH)

azkare --help
الأمرالوصف
azkareتشغيل في الخلفية (الطبقة + شريط المهام)
azkare --foregroundالبقاء في الطرفية
azkare --settingsفتح نافذة الإعدادات
azkare --nextالذكر التالي فورًا
azkare --mode overlay|notify|bothوضع العرض: سطح المكتب / إشعارات / الاثنان
azkare --autostart on|offالتشغيل عند بدء النظام
azkare --update [--force]التحديث: يفحص GitHub ثم يسحب ويعيد البناء ويعيد التشغيل
azkare --uninstall [--purge]إلغاء التثبيت (مع --purge يحذف الإعدادات والمصدر)
azkare --quitإيقاف النسخة العاملة
azkare --statusالحالة والإصدار ومسار الإعدادات
azkare --versionالإصدار + hash + تاريخ البناء
azkare --helpدليل الاستخدام ثنائي اللغة
